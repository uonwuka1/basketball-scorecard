# 🏀 Basketball Scorecard

A simple, responsive scoreboard for tracking a basketball game between a Home and Guest team.

**Live demo:** https://uonwuka1.github.io/basketball-scorecard

## Features
- Add 1, 2, or 3 points for either team
- Reset each team's score independently
- The leading team's score is highlighted automatically

## Built With
- HTML5
- CSS3 (Flexbox layout)
- Vanilla JavaScript (DOM manipulation, event listeners)
- Vite (development server)

## Run Locally
```bash
git clone https://github.com/uonwuka1/basketball-scorecard.git
cd basketball-scorecard
npm install
npm run dev
